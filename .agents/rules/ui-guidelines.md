# UI Development Guidelines & Required Workflow

Whenever building, modifying, or redesigning any UI screen or component in this repository:

1. **Mandatory Skill Review**: Always call `view_file` on `p:/sd-sim/.agents/skills/frontend/SKILL.md` before writing code.
2. **Design Read Requirement**: Print the one-line Design Read:
   `"Reading this as: <page kind> for <audience>, with a <vibe> language, leaning toward <aesthetic>."`
3. **Calibrate Dials**:
   - `DESIGN_VARIANCE`
   - `MOTION_INTENSITY`
   - `VISUAL_DENSITY`
4. **Anti-Congestion Rule**:
   - Avoid walls of text on mobile screens.
   - Use scannable visual metrics, badges, and quick-action triggers.
   - Keep Home screen concise (Hero action + compact framework glance + daily insight + jump back to practice).
